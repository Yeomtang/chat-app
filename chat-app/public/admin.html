진행 제어

실시간 채팅 — 클릭하면 LED에 핀 고정

진행자/패널이 언급할 채팅을 클릭하면 LED 중앙에 팝업으로 고정됩니다. 다른 채팅을 클릭하면 교체되고, [핀 내리기]로 해제합니다.

주관식 답변 목록 — 픽하면 LED에 크게 표시

훑으면서 괜찮은 답변에 ☆(후보)를 눌러두고, [픽]을 누르면 LED 중앙에 스포트라이트로 8초간 표시됩니다. 별표는 관리자 화면끼리 공유되므로 여러 명이 나눠서 볼 수 있습니다.

아직 답변이 없습니다
