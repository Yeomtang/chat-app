# 실기기 LTE 테스트 체크리스트

행사 전에 실제 폰으로 한 번은 꼭 돌려 볼 항목입니다. 운영 주소 `https://chat-app-s6y2.onrender.com` 기준.

## 준비
- 폰: 아이폰 1대 이상(Safari), 안드로이드 1대 이상(Chrome·삼성 인터넷). 가능하면 구형 기종 1대 포함
- 화면: LED(`/led` 또는 `/led/concert`) 1대, 관리자(`/admin`) 1대, 운영진(`/host`) 1대
- Render 무료 플랜이면 시작 5분 전에 아무 화면이나 열어 서버를 깨워 둔다(첫 접속 30~60초 지연)
- 모든 화면 새로고침(배포 이후 열려 있던 화면은 묶음 채팅을 못 받음)

## 1. 입장
- [ ] QR 스캔 → 페이지가 5초 안에 뜬다 (LTE, 와이파이 끈 상태)
- [ ] 닉네임이 보이고 [다른 닉네임] 버튼이 동작한다
- [ ] 입장 후 이전 채팅(최근 50개)이 보인다

## 2. 채팅
- [ ] 보낸 채팅이 1초 안에 내 폰·LED·관리자 화면에 뜬다
- [ ] 한글 입력 중 Enter(조합 중)로 엉뚱하게 전송되지 않는다
- [ ] 100자 제한·80자부터 카운터 표시
- [ ] 빠르게 6번 연속 전송 → "너무 빨리 보내고 있어요" 빨간 띠, 마지막 메시지가 입력창에 되살아난다
- [ ] 욕설 입력 시 `*`로 가려진다
- [ ] 관리자/운영진이 삭제하면 내 폰에서도 사라진다

## 3. 연결 끊김 (가장 중요)
- [ ] 비행기 모드 켜기 → 몇 초 안에 "연결이 끊겼어요. 다시 연결하는 중…" 띠
- [ ] 끊긴 상태에서 전송 → 보내지지 않고 입력 내용이 남아 있다
- [ ] 비행기 모드 끄기 → 띠가 사라지고, 끊긴 동안 다른 사람이 보낸 채팅이 보인다
- [ ] 와이파이 ↔ LTE 전환 중에도 같은 동작
- [ ] 화면 잠금 1분 → 잠금 해제 후 다시 연결되고 채팅이 이어진다
- [ ] 다른 앱으로 갔다가(백그라운드 1분) 돌아와도 동일

## 4. 투표·질문
- [ ] 관리자가 YES/NO 시작 → 폰에 투표 카드·30초 타이머, 채팅 입력 막힘
- [ ] 투표 → LED 공 애니메이션에 반영, 답 변경 가능
- [ ] 투표 중 비행기 모드 켰다 끄기 → 투표 화면이 그대로 복구되고, 끊긴 동안 누른 표도 집계된다
- [ ] 타이머 종료 → 결과(%) 표시, 붐업/붐따 버튼 동작
- [ ] 객관식(N지선다)·주관식·이모지 질문도 각각 1회 진행
- [ ] 채팅 모드 복귀 후 바로 채팅 가능

## 5. 운영 화면
- [ ] 관리자: 질문 [내보내기] 파일이 받아진다 → [불러오기]로 다시 넣을 수 있다
- [ ] LED: 관리자 [멈추기]/[재생], 핀 고정/해제
- [ ] LED 화면을 새로고침해도 현재 모드(채팅/투표/결과)로 바로 복구된다

## 기록할 것
- 폰 기종·OS·브라우저, 통신사
- 문제가 난 항목, 재현 순서, 대략적인 시각(서버 로그와 맞춰 보기 위함)
